# Archive_Mole
perfect for digging up the past in a calm and orderly fashion

## Installing on your phone

This app is installable as a PWA (Progressive Web App) once hosted somewhere
over `https://` — e.g. GitHub Pages. `manifest.json`, `sw.js`, and `icons/`
give it a name, an app icon, and a minimal offline shell cache so it behaves
like a real app on your home screen instead of just a bookmark.

1. Make this repo public (Settings → Danger Zone → Change visibility), then
   enable GitHub Pages (Settings → Pages → Deploy from branch → `main` → `/`
   root).
2. Once it's live, open `https://<your-username>.github.io/Archive_Mole/Archive_Mole.html`
   on your phone (the filename matters here — the app isn't named
   `index.html`).
3. Use your browser's "Add to Home Screen" / "Install app" option.
