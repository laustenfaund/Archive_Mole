Why this only translates one direction, and why it isn't 100%

U/I only reworks neurodivergent → neurotypical phrasing, on purpose. Miscommunication between neurotypes is a two-way problem, not a one-sided deficit — but in practice, the work of crossing that gap already falls disproportionately on neurodivergent people. This tool meets people where that labor already sits; it isn't claiming to fix the imbalance itself.

It also won't claim a message translated completely when it didn't. Some things genuinely don't have a clean neurotypical-legible equivalent — U/I will say so in a note rather than quietly smoothing over what got lost.

Your API key, voice notes, and any archive-derived messages are stored only in this browser, on this device, and are never sent anywhere except directly to Anthropic when you translate. There is no account, no backend, and no export — the "clear all local data" button really deletes it.
