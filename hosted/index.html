AI Assistant — hosted, passcode-gated

Enter your access passcode to let an assistant run the search brief live against this archive — filtering, searching, and reading conversations as it goes, right here, instead of you copying the brief out by hand.

This build doesn't use your own API key. Requests go to a small proxy the app owner runs, which holds the real Anthropic key and enforces spending limits — your passcode identifies you to it. That means, unlike the plain version of this app, whatever you ask the assistant (and the matching parts of your archive it reads to answer) does leave your browser, bound for that proxy and then Anthropic. Your passcode itself is stored only in this browser's local database. If you weren't given a passcode, ask whoever runs this instance for one.
